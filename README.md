# Runecast — расклады рун и Таро

Telegram Mini App: выбираешь тип расклада, тянешь карты или руны, читаешь трактовку.
Живёт на GitHub Pages: https://feeltheambience.github.io/runecast/

Статика: `index.html`, `app.js`, `style.css`. Расклады и тексты трактовок зашиты в `app.js`.

Запуск локально — открыть `index.html` в браузере. Для проверки внутри Telegram нужно прописать URL в @BotFather как Web App.
